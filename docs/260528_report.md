### D-2. 엑셀(구글 시트) 다운로드 동작 확인
**문제 보고**: 사용자분 — "엑셀 다운로드 버튼이 구글 시트 내용을 안 받음".

**현재 구현**: 버튼이 `https://docs.google.com/spreadsheets/d/{ID}/export?format=xlsx` 를 새 탭으로 엶.

**확인 부탁**: 
1. https://docs.google.com/spreadsheets/d/1PSTO5GFT0RljdTy_uJrl-JTHohspoXMy4-Lybhg9HtA/edit 직접 접속 가능?
2. 안 보이면 시트 공유 설정에서 본인 이메일 추가 필요
3. 보이면 export URL 도 자동으로 동작

**D-2a 결정 필요** (위 1번 결과에 따라):
- 🅐 **그대로 유지** (사용자 본인이 시트 권한 있어야 동작 — 운영팀만 쓰니 OK)
